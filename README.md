# 旅するタイマー

勉強した時間だけ、地図の上を旅するタイマーです。

- **国内版:** 新幹線 (1分 = 3 km)。東京 → 鹿児島中央。きっぷを集めます。
- **海外版:** 飛行機 (1分 = 10 km)。東京 → パリ。パスポートのスタンプを集めます。
- 目的地を選ぶと、現地の写真と名物が出ます。到着すると写真つきのカードが出ます。
- 連続日数、称号、今日の目標、過去7日間のグラフがあります。
- 記録はブラウザーの中 (localStorage) だけに保存します。サーバーやログインはありません。

## 自分の PC で動かす

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで http://127.0.0.1:8000/ を開きます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | タイマー、記録、目的地、きっぷ / スタンプ |
| `map.js` | 地図の上で新幹線 / 飛行機を動かす |
| `map-data.js` | 地図の形 (自動生成) |
| `photos/` `photos.js` | 現地の写真と撮影者の情報 (自動生成) |
| `tools/` | `map-data.js` と `photos/` を作り直すスクリプト |

## 地図と写真の出典

- 地図: [Natural Earth](https://www.naturalearthdata.com/) (パブリックドメイン)。`tools/build-map.mjs` で変換しています。
- 写真: [Wikimedia Commons](https://commons.wikimedia.org/) の自由に使える写真を、幅960pxに縮小して使っています。撮影者とライセンスは `photos/CREDITS.md` と、画面の下の「写真と地図のクレジット」にあります。`tools/fetch-photos.mjs` で取得しました。
